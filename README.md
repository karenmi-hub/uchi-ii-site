# Учи ИИ — сайт

Публичная версия сайта платформы «Учи ИИ»: **https://karenmi-hub.github.io/uchi-ii-site/**

Это витрина на GitHub Pages: страницы, курсы, тренажёр, подбор профессии и курс «ML для продвинутых».
Функции, которым нужен сервер, — вход в кабинет, оплата, чат с ИИ, туры по кнопкам — здесь
показывают сообщение «сервер ещё не подключён» и заработают на боевом домене.

Файлы в этом репозитории собираются автоматически (`build_site.py` в основном проекте). Правки
делайте в основном проекте, а не здесь.
